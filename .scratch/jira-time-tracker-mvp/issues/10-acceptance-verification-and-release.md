## Acceptance criteria

- [ ] Все приёмочные сценарии A01–A19 из раздела 12 спецификации реализованы в автоматических тестах и проходят (`flutter test`).
- [ ] Форматирование кода полностью соответствует стандартам Dart (`dart format --output=none --set-exit-if-changed lib test`).
- [ ] Статический анализ завершается без ошибок и предупреждений (`flutter analyze`).
- [ ] Успешно собирается релизный бинарный пакет Windows Desktop (`flutter build windows --release`) со всеми необходимыми библиотеками и data-файлами.
- [ ] В корне создан понятный и подробный `README.md`, описывающий:
  - Инструкцию по сборке и запуску Windows-приложения.
  - Настройку трех параметров подключения (ввод в UI и переменные окружения).

  - Особенности работы оффлайн, таймеров при закрытии приложения/сне Windows.
  - Ограничения поиска давних worklogs и алгоритм разрешения статусов `unknown`.
- [ ] Сформирован финальный отчёт исполнителя с перечислением результатов команд, пути к собранному release bundle и статуса проверки live API.
