# 04: Таймеры и ручной ввод времени (Play/Pause, сохранение при рестарте)

**What to build:** Управление временем работы над задачами. Создание записей в таблице `LocalLog`. Поддержка ручного ввода («Добавить время» на 3 часа без запуска таймера), независимые параллельные таймеры на разных задачах, чистый модуль `LogClock` для вычисления прошедшего времени по сохранённым UTC-отметкам, сохранение состояния при закрытии процесса и сне Windows.

**Blocked by:** 03: Добавление и кэш задач (по ключу, ID, URL)

**Status:** ready-for-agent

## Acceptance criteria

- [ ] Ручной ввод времени («Добавить время»): создание остановленного локального лога на произвольное время (например, 3 часа = 10 800 секунд) с опциональным описанием без запуска таймера и без запросов к Jira (сценарий A01).
- [ ] Параллельные таймеры: одновременный запуск таймеров на нескольких разных задачах создает независимые записи одинаковой длительности (сценарий A02).
- [ ] Модуль `LogClock` вычисляет прошедшее время по `accumulatedSeconds + (nowUtc - runningSinceUtc)`. Закрытие приложения, выключение процесса или сон Windows корректно учитывают прошедшее время при повторном запуске (сценарий A03).
- [ ] Действие Play продолжает текущий лог задачи, Pause останавливает и фиксирует прошедшее время; время паузы исключается из подсчёта (сценарий A03).
- [ ] Действие «Новый лог» останавливает предыдущий таймер задачи (если он был запущен) и создает отдельную запись; ручной ввод при активном таймере не перезаписывает и не удваивает другие таймеры (сценарий A04).
- [ ] Отрицательная разница времени при откате системных часов Windows распознается как ошибка и требует проверки лога.
- [ ] Написаны тесты таймеров и ручного логгирования, покрывающие сценарии A01, A02, A03, A04.
