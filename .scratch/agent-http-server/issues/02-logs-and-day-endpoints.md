# Ticket 02: Эндпоинты управления логами и загрузки собранного дня (/api/logs, /api/day)

## Описание
Реализовать обработчики бизнес-логики в `AgentApiServer`:
1. `GET /api/logs`: выдача списка свободных логов активного scope.
2. `POST /api/logs`: логирование времени по `issue_key` (минуты или секунды, опциональное описание). Если задачи нет в кэше — поиск/загрузка через JiraClient и сохранение в кэш.
3. `PATCH /api/logs/{id}`: изменение времени и описания свободного лога.
4. `DELETE /api/logs/{id}`: удаление свободного лога.
5. `GET /api/day?date=...`: получение существующих записей Jira и текущего черновика дня со списком сегментов и пауз.
6. `POST /api/day`: сохранение построенного агентом расписания дня:
   - Поддержка форматов времени начала: `"HH:MM"` локального времени и ISO-8601 UTC.
   - Автоматическая привязка к существующим или вновь созданным `LocalLog`.
   - Валидация расписания через `DayBuilder.validate`.
   - Сохранение `DayDraft` в `LocalStore` и обновление состояния UI через `AppState`.
7. Тесты всех маршрутов и граничных случаев в `test/agent_api_endpoints_test.dart`.
