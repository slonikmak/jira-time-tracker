# 05: Очередь неиспользованных логов и управление записями

**What to build:** Панель очереди неиспользованных логов на экране «Работа». Отображение свободных записей с названием задачи, длительностью, датой создания и описанием. Редактирование длительности и описания остановленных свободных логов, удаление записей, доступность логов независимо от даты их создания (включая прошлую неделю).

**Blocked by:** 04: Таймеры и ручной ввод времени (Play/Pause, сохранение при рестарте)

**Status:** ready-for-agent

## Acceptance criteria

- [ ] В правой панели экрана «Работа» отображается список всех неиспользованных (`consumedAtUtc == null`) и не включенных в черновики логов.
- [ ] Логи, созданные в прошлые дни (например, на прошлой неделе), остаются доступными в очереди и могут быть выбраны для сборки на любую дату (сценарий A11).
- [ ] Остановленный свободный лог можно отредактировать (изменить длительность в часах/минутах, описание) или удалить из базы (сценарий A04).
- [ ] Соблюдается четкое разделение: summary Jira-задачи (заголовок, фиксируемый при создании лога) vs пользовательское описание работы (сценарий A04).
- [ ] Для активных (запущенных) логов в очереди отображается статус «В процессе» с кнопкой паузы, без возможности включить их в сборку до остановки.
- [ ] Написаны тесты управления очередью и проверки сценариев A04 и A11.
