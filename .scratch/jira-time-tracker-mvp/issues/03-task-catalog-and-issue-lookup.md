# 03: Добавление и кэш задач (по ключу, ID, URL)

**What to build:** Добавление задач Jira в локальную базу данных (таблица `Issue`) по ключу задачи (`PROJ-123`), числовому issueId или веб-ссылке (`/browse/PROJ-123`). Получение заголовка (summary) через `JiraClient`. Список недавних задач на экране «Работа» с сортировкой по времени последнего действия и фильтрацией давности.

**Blocked by:** 01: Каркас Flutter Desktop, SQLite, single-instance lock и навигация, 02: Настройки подключения к Jira (Env, SecureStore, проверка маршрутов)

**Status:** ready-for-agent

## Acceptance criteria

- [ ] Поле ввода задачи корректно разбирает текстовый ключ (например, `PROJ-123`), числовой ID и ссылку браузера (например, `https://domain.atlassian.net/browse/PROJ-123` или `/browse/PROJ-123`).
- [ ] `JiraClient.getIssue` запрашивает GET `/rest/api/3/issue/{idOrKey}?fields=summary`, получает канонический ключ и summary.
- [ ] Добавление задачи, назначенной на другого пользователя, разрешено и создает строку задачи (сценарий A05).
- [ ] Повторный ввод уже добавленной задачи не создает дубликат, а поднимает существующую задачу наверх списка (`lastUsedAtUtc`).
- [ ] Список задач на экране «Работа» сортируется по активности (добавление, запуск таймера, ручной лог), поддерживает поиск по ключу/названию и фильтры давности («7 дней / 30 дней / Все»), не удаляющие данные.
- [ ] Написаны тесты парсера ключей/URL и интеграционные тесты сохранения задач в SQLite.
